## Что изменилось

- **C4 / F4.** Добавлен `scripts/validate_html.py`. Он детерминированно проверяет пару Markdown/HTML, структуру, якоря, маркеры-заглушки, внешние зависимости, BCP 47 `lang`, метаданные, CSS и перенос исходных URL.

- **C7 / F7.** Атрибут `lang` должен совпадать с реальным языком документа. Русский редакторский конвейер запускается только для русской прозы.

## Зачем нужны эти изменения

- **C4:** объективные свойства HTML проверяются одинаково при каждом запуске. Факты, язык и внешний вид по-прежнему оцениваются отдельно, где автоматический тест не поможет.
- **C5:** правило теперь меняется у одного владельца, поэтому доставка, браузер и завершение не разъедутся после следующего обновления.
- **C6:** по результату видно, что проверяющий нашёл и что осталось спорным; формальная отметка без следа больше не проходит.
- **C7:** английский отчёт получает правильную языковую метку и не ломает доступность ради русского значения по умолчанию.
