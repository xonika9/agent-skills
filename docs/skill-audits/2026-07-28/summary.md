## Фактические изменения

- **C1 / F1:** Opus- и GPT-маршруты явно выбирают модель обещанного семейства.
- **C2 / F2:** Claude Code и Codex получили отдельные адаптеры с живой проверкой возможностей.
- **C3 / F3:** режим `full` объявляет точную матрицу линз и провайдеров.
- **C4 / F4:** машинные требования к Markdown/HTML проверяет `validate_html.py`.
- **C5 / F5:** доставка, HTML, источники и браузерная безопасность получили по одному владельцу.
- **C6 / F6:** независимая проверка оставляет краткий итог рядом с реестром утверждений.
- **C7 / F7:** HTML использует фактический BCP 47 `lang`; русский конвейер больше не навязывается английскому отчёту.

## Зачем нужны эти изменения

- **C1:** нельзя выдать другую модель за обещанного критика.
- **C2:** изменения среды не засоряют стабильный метод и правятся в одном адаптере.
- **C3:** стоимость и критерий завершения `full` больше не плавают.
- **C4:** одинаковый HTML-контракт проверяется одной командой.
- **C5:** параллельные копии правил больше не расходятся.
- **C6:** независимая проверка оставляет доказательство, а не голую отметку.
- **C7:** языковая метка HTML совпадает с содержимым документа.
