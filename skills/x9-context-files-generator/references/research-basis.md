# Research basis for context files

The 2026 study *Evaluating AGENTS.md* found that context files increased instruction following and cost but did not improve task success on average; repository overviews were especially weak on average. The result argues against generic, inferable context, not against every architecture explanation.

Apply the narrower rule:

- Include information that changes agent behavior and is expensive or impossible to infer from the repository.
- Exclude generic descriptions and inventories that repeat visible structure.
- Measure representative tasks when adding large instruction blocks; instruction compliance alone is not proof of better outcomes.
- Preserve nonstandard local practices because the study found that such instructions can still be useful.

Source: https://arxiv.org/abs/2602.11988 (use the current version when citing conclusions).
